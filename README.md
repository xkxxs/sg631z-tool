# sg631z-tool

锐捷 / 星网锐捷 **SG631Z** 系列联通光猫「超级账户」提取工具 —— **只读、单文件、零依赖**。

用光猫背面贴纸上的普通账户登录，通过设备自带的隐藏命令页解密配置库，读出
`DevAuthInfo` 表里的全部 Web 账户（含超级管理员）。全程不修改任何设置，结束后自动删除设备上的临时文件。

> ⚠️ 仅限在你本人拥有管理权限的设备上使用。未经授权对他人设备使用属于违法行为，作者不承担任何责任。

## 适用设备

| 设备 / 固件 | 状态 | 说明 |
|---|---|---|
| SG631Z（联通，星网锐捷/锐捷） | ✅ 真机验证 | `hidden_cmd.gch` + `sidbg`，2026-08 固件 |
| SG631Z-C / 吉比特同类固件 | ⚠️ 理论可用 | 同为 `hidden_cmd.gch` + `sidbg` 体系 |
| 中兴标准 `.gch`（UNG220Z、F7607P 等） | ❌ 不适用 | 没有 `hidden_cmd.gch`，需别的工具 |
| 华为 `ssmp` / 烽火 `cgi-bin` | ❌ 不适用 | 框架完全不同 |

判断方法：登录后台后能打开下面的页面，就说明适用：

```
http://192.168.1.1/hidden_cmd.gch?pwd=aDm8H%25MdA
```

## 使用环境

- **Python 3.8+**（Termux、Linux、macOS、Windows 均可）
- **纯标准库**：AES-128-CBC 已内置，无需 `pip install`，无需 root
- 设备与光猫在**同一局域网**，浏览器能打开 `http://192.168.1.1`
- 需要光猫**背面贴纸**上的普通账户（用户名一般为 `user`，密码形如 `t6kpk5rw`）

## 使用方法

```bash
git clone https://github.com/xkxxs/sg631z-tool.git
cd sg631z-tool
python3 sg631z.py
```

交互式依次输入：光猫地址（默认 `192.168.1.1`）、用户名、密码（输入不显示）。

也可以全部走命令行参数：

```bash
python3 sg631z.py -H 192.168.1.1 -u user -p '贴纸密码'
python3 sg631z.py -H 192.168.1.1 -u user -p '贴纸密码' --verify   # 附带验证超管能否登录
python3 sg631z.py -H 192.168.1.1 -u user -p '贴纸密码' --json     # 机器可读输出
python3 sg631z.py -H 192.168.1.1 -u user -p '贴纸密码' --exec 'id' # 只执行一条命令
python3 sg631z.py --selftest                                      # 内置 AES 自检
```

### 参数

| 参数 | 说明 |
|---|---|
| `-H, --host` | 光猫地址，默认 `192.168.1.1` |
| `-u, --user` | 普通账户，默认 `user` |
| `-p, --password` | 普通账户密码，不填则交互输入 |
| `--su-pass` | 隐藏命令页的 `pwd` 参数，默认 `aDm8H%MdA` |
| `--verify` | 用找到的管理员账户再登录一次验证（只尝试 1 次，避免触发锁定） |
| `--exec CMD` | 只通过隐藏命令页执行一条命令并打印输出 |
| `--json` | 以 JSON 输出账户表 |
| `--no-clean` | 保留设备上的 `/tmp/debug-decry-cfg`（默认删除） |
| `--timeout` | 网络超时秒数，默认 8 |
| `--selftest` | 运行 FIPS-197 AES 自检后退出 |

### 退出码

`0` 成功 / `1` 参数或密码为空 / `2` 网关不可达 / `3` Web 登录失败 / `4` 隐藏命令页不可用 / `5` 配置解析失败 / `130` 用户中断

## 原理

1. **Web 登录**：该固件前端用 AES-128-CBC 加密账号密码（key/iv 均为固定的 16 位数字串，PKCS#7 填充，输出 Base64），并回填页面下发的 `Frm_Logintoken` / `csrf_token` / `session_token`。脚本内置了纯 Python 的 AES 实现，按同样规则登录；普通用户走首页，`CUAdmin` 走 `cu.html`。
2. **隐藏命令页**：登录后 `hidden_cmd.gch?pwd=...` 会返回一个可执行 shell 命令的文本框（等价于 root 命令通道）。
3. **解密配置**：`sidbg 1 DB decry /userconfig/cfg/db_user_cfg.xml` 生成明文 `/tmp/debug-decry-cfg`，再取其中 `DevAuthInfo` 表（包含 `User` / `Pass` / `Level`）。
4. **清理**：无论成功失败，都会执行 `rm -f /tmp/debug-decry-cfg`。

脚本对 `sendcmd` 体系做了自动回退（先 `sidbg`，失败再 `sendcmd`）。

## 常见问题

### 登录提示失败 / 被锁

设备连续 **3 次**密码错误会进入延时校验，页面显示「错误登录次数已经达到三次，系统将延时进行校验」。
此时**不要再试**，静默等待 10~30 分钟；确认用的是背面贴纸上的普通账户。

### `hidden_cmd.gch` 返回 404 / 403

- 固件不是 SG631Z 同类（见上方兼容表）
- 或 `pwd` 已被改动，可用 `--su-pass` 指定

### 读到了超管密码，但登录提示错误

- 超管密码会被 TR-069 周期性轮换，隔一会儿重跑脚本即可
- 管理员入口是 `http://192.168.1.1/cu.html`，不是首页的「其它账户」
- 部分省份用「`CUAdmin` + SN 后 8 位」或干脆空密码，可都试一次（注意 3 次上限）

### 恢复出厂后没有超级账户

先拔掉光纤，用 `CUAdmin / CUAdmin` 登录 `cu.html`，在管理页开启 Telnet 或直接跑本脚本；
拿到 LOID / 密码后重新注册即可。**恢复出厂前请先记录 LOID、宽带账号、VLAN 等配置。**

## 安全提醒

- 明文密码会显示在终端里，注意旁人视线与 shell 历史（可用 `-p` 传参避免交互记录）
- 拿到超管密码后建议登录后台修改，且不要再使用贴纸密码作为管理密码
- 本工具只读配置；`--exec` 请勿执行会改动设备的命令
